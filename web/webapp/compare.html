Compare two versions of a bill

Upload the start and end versions — two PDFs or two bill-XML files. We diff them on our server and open a full HTML report in a new tab — sidebar navigation and word-level changes. Your session is not tracked, and uploaded files are processed in memory and never stored.

Your files are processed on our server. Please don't upload drafts or other non-public bill text here — for pre-publication material, run the tool on your own machine instead (see the README). A fully local version that keeps everything on your device is planned.

File type

The report also has a full-bill view (read the whole bill with changes marked inline) and an Export button: download the comparison as diff.json and ask an AI assistant (ChatGPT, Claude, or Copilot) to explain what changed, using the ready-made prompts we include.
